# PyLibTest

A testing ground for Python library development and packaging structure.

## 📂 Structure

This repository demonstrates a standard Python package layout:

*   `src/`: Source code directory.
*   `pyproject.toml`: Build system configuration.
*   `setup.cfg`: Package metadata and options.

## 🧪 Usage

This is a template/sandbox for expecting with Python packaging tools like `build` and `twine`.
